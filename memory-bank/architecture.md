# Project architecture

This is a static mockup of a planned website overview for a client. We will be using semantic HTML and Tailwind CSS delivered via a CDN.

## Tech Stack

- `npx http-server` or `python server.py` to serve
- `tailwindcss@latest` for styling
- Schema.org and meta tags for SEO
- ARIA properties for accessibility

## Directory Structure

- `index.html`: Home page
- `style.css`: Custom styles if needed
- `static/`: Static assets
- `catalog/index.html`: Product catalog
- `product/index.html`: Single product view
- `cart/index.html`: Cart view
- `checkout/index.html`: Product checkout
